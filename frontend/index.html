Pydantic Type Validation

Incoming request payloads are strictly parsed and validated against typed Python models. Invalid fields return automatic HTTP 422 Unprocessable Entity responses with detailed location hints.

Fast Streaming Responses

The batch CSV processing endpoint utilizes FastAPI's StreamingResponse with in-memory io.StringIO buffers to stream annotated CSV files directly back to client browsers without saving temporary files to disk.
